Status column reflects real evidence gathered from an actual played session's `logs/latest.log`
(`Summerpack-1.1.8` Prism instance, played 2026-07-21), a headless dedicated-server boot (1.1.9),
direct file inspection, and the user's own real in-game playtest with screenshots (multiple
rounds). Legend: ✅ confirmed working (either by log evidence or the user's own playtest),
⚠️ partial/indirect evidence, 🔴 real bug found (fixed unless noted), ❔ still needs interactive
gameplay. See `changelog.md` for full history, especially the "Round N" sections.

Reorganized so confirmed-working items are grouped first, followed by everything still needing a
look, followed by items removed/deprecated/discarded. Original `#` numbers kept as stable IDs for
cross-referencing the changelog - they're no longer in sequential order after this reorganization,
that's expected.
